# 월별 통계 재집계 — 2026-10-17

공개 Monthly 데이터가 7월 1건에서 갱신되지 않았지만, 운영 DB의 8~10월 수집 실행 이력은 남아 있었다.
누락된 월별 통계를 ops.pipeline_run에서 읽기 전용으로 재집계했다.

## 집계 방법과 해석

- 완료 시각을 한국 시간으로 변환해 월을 나눈다. 10월은 10/17 현재까지의 월중 집계다.
- 각 월의 마지막 성공 청크를 선택하되 시군구 코드가 겹치는 수집을 중복 합산하지 않는다.
- 청크 조합으로 전국 범위를 덮을 수 없으면 해당 월의 마지막 전국 전체 성공 실행을 사용한다.
  7월은 이 방식으로 7/30 전국 실행을 사용하며, 기존 Monthly의 7월 수치와 일치한다.
- 8~10월은 각각 6개 성공 청크를 조합했다. 모든 월에서 설정된 269개 시군구 코드의 범위를
  정확히 한 번씩 덮는지 검증했다. 이는 객체가 존재하는 시군구 수와 다른 지표다.
- 성공/실패 실행 수는 재시도 및 시험 수집을 포함한 실행 횟수다. 수집 객체 수는 이 반복 횟수를 합산하지 않는다.
- 실패 실행은 객체 수의 근거로 사용하지 않았다. 일부 지역의 마지막 성공일이 월말보다 이른 점은
  실제 수집일 범위로 표시했다. 미관측 변경이 없었다고 보장하지 않는다.
- 이 결과는 수집 이력에 근거한 통계 복원이며, 월말 동시 원본 스냅샷 또는 별도 원본 백업의 복원이 아니다.

## 재현과 검증

- 집계 코드: scripts/export_monthly_statistics.py (DB SELECT만 수행)
- 검증 노트북: docs/monthly_statistics_recovery_20261017.ipynb
- 결과 CSV: docs/monthly_statistics_recovery_20261017.csv
- 기존 Monthly 호환 결과: dashboard/data/monthly_archives.json
- 구조화된 결과와 근거 실행 ID: dashboard/data/monthly_statistics.json
- 반복 수집, 범위 중복, 전국 실행 대체, 누락 범위, 한국 시간 월 경계 회귀 테스트 4개 통과.

기존 Monthly에 누락 통계와 실제 수집 기간·집계 상태를 반영한다.
사용자의 추가 승인에 따라 일일 대시보드 내보내기에서도 월별 통계를 재생성하도록 연결한다.
기존 메인 대시보드 레이아웃은 유지한다.
